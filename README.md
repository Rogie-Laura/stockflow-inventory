# PinoyStock — Inventory, POS & Monitoring para sa Pinoy Negosyo

All-in-one SaaS platform: inventory management, POS terminal, at live monitoring dashboard. **Simula ₱100/buwan lang!**

## Presyo

| Plan | Buwanan | Taunan (tipid ₱900) |
|------|---------|---------------------|
| **Standard** | ₱100/buwan | ₱1,200/taon |
| **Enterprise** | ₱200/buwan | ₱2,400/taon |
| **Enterprise A Plus** | ₱1,500/buwan | ₱17,100/taon |

## Features

- **Transactions** — Lahat ng sales at POS records
- **Point of Sale (POS)** — Cash, Card, E-Wallet, resibo
- **Monitoring Dashboard** — Live sales, stock alerts, analytics
- **Inventory** — Products, categories, suppliers
- **Auth** — Supabase login/signup
- **Dark Mode** — Light / dark / system

## Tech Stack

Next.js 16 · Tailwind CSS v4 · shadcn/ui · Supabase · Recharts

## Getting Started

```bash
npm install
npm run dev
```

- Local: http://localhost:3000
- Live: https://inventorysystem-lemon.vercel.app
- GitHub: https://github.com/Rogie-Laura/stockflow-inventory
- Supabase: stockflow-inventory project

## Supabase Setup

Copy `.env.local.example` to `.env.local` at ilagay ang keys mula sa Supabase Dashboard.
